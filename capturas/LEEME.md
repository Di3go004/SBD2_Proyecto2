# capturas

Todas las capturas deben mostrar **la fecha y hora del sistema operativo** (el reloj de la barra de tareas visible). Si no se pueden tomar en pantalla completa, corran `date` en la terminal justo antes.

Nombres sugeridos, una carpeta por tipo (`anio/`, `deporte/`, `deportista/`):

```
<paso>_<momento>_<que>.png
0_carga_validar.png         1_carga_ver_tablas.png
0_backup_full.png           1_backup_diff.png
r0_restore_full.png         r0_restore_validar.png
r3_restore_diff.png         r3_restore_validar.png
```
